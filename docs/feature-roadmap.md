# 機能ロードマップ候補

## 判断原則

個人情報の隠し忘れ防止、確認、アクセシビリティは安全性の中核なので無料版に残します。有料版は作業時間を短縮する機能と高度な編集機能で価値を作ります。

## 無料版で優先する機能

| 優先度 | 機能 | 理由 |
|---|---|---|
| 高 | 手動マスクの移動・リサイズ | 検出位置の微調整は安全性の中核 |
| 高 | Undo／Redo | 誤操作から安全に戻せる |
| 高 | 保存前のマスク漏れ確認 | アプリの主目的に直結 |
| 中 | 加工前／加工後の比較 | 隠しすぎ・隠し忘れを確認しやすい |
| 中 | VoiceOver向け領域一覧編集 | 視覚だけに依存しない操作を提供 |
| 中 | 一時データの自動破棄タイマー | プライバシー訴求を強化 |

## 有料版に適した機能

| 優先度 | 機能 | 課金価値 |
|---|---|---|
| 高 | 複数画像の一括処理 | 繰り返し作業を大幅に短縮 |
| 高 | PDF読み込み・複数ページPDF書き出し | 業務・申請用途で明確な価値がある |
| 実装済み | マスクプリセットの保存・再利用 | マスク方式・安全余白・対象種別を名前付きで再利用 |
| 一部実装済み | 安全余白の調整 | 文字の端が残るリスクを抑える3段階に限定 |
| 基盤実装済み | 書類ごとの一括ルール適用 | 現在の画像へ推奨ルールを一括適用。将来の複数画像処理でも再利用可能 |

## 課金対象にしない機能

- OCR候補検出の基本精度
- マスク漏れ警告
- EXIF削除
- 端末内処理
- アクセシビリティ対応

安全性やプライバシーを課金壁にすると、無料ユーザーの事故リスクを高め、Sumiの信頼性を損なうためです。
