# TestFlight 最終QA

## 自動検証済み

- Debugビルド
- Release実機向けビルド（署名なし）
- Unit Test 25件
- プライバシーマニフェスト同梱
- App Icon 1024×1024、アルファなし
- App Group識別子の本体／Share Extension一致
- 公開プライバシーポリシーのHTTP 200

## TestFlightビルドで実施するスモークテスト

### インストール・起動

- 新規インストールでオンボーディングが一度だけ表示される
- アップデート後も既存のプリセットが保持される
- オフライン状態でも購入以外のマスキングが完了する

### 入力

- カメラ撮影
- カメラロールから縦／横／HEIC／高解像度画像を選択
- 写真アプリの共有メニューからSumiを起動
- Siri／ショートカットから起動

### 検出・編集

- 免許証、マイナンバーカード、保険証、パスポート、その他
- 日本語、全角数字、郵便番号、電話番号、日付、QRコード
- 候補ON／OFF、手動追加、長押し削除、リセット
- 候補ゼロ件時とマスクゼロ件時の警告

### 書き出し

- 黒塗りとモザイク
- 標準／広め／最大の安全余白
- 保存画像でマスク位置と向きを確認
- 位置情報・EXIFが引き継がれていないことを確認
- 写真アクセス拒否時の案内
- 保存後に元画像と検出位置が破棄される

### アクセシビリティ・表示

- VoiceOverで主要フローを完走
- Dynamic Type最大
- ライト／ダークモード
- iPhone SE相当の小画面と大型iPhone
- 日本語環境で文言切れがない

### Sumi Plus

- 購入、キャンセル、復元、オフライン時の表示
- 透かしの有無
- 安全余白とプリセットのロック解除
- プリセット保存、上書き、適用、削除

## 合格条件

- クラッシュ、画像漏えい、マスク位置ずれ：0件
- 主要フローを妨げる不具合：0件
- VoiceOverで操作不能な主要機能：0件
- Releaseビルドの新規警告：0件

Apple Developer Program、署名、App Store Connectのアプリ作成、RevenueCat本番キーと商品設定が完了後、Archiveをアップロードしてこのチェックリストを実機TestFlightビルドで実施します。
