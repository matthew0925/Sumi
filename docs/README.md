# Sumi

本人確認書類・個人情報を含む画像を、撮影するだけで自動マスキングするiOSアプリの関連資料です。

## 中身
- `Sumi_技術仕様書.md` — プロダクト概要、MVPスコープ、実装方針、プライバシー設計、マネタイズ、開発ロードマップ、リスク評価
- `aso-materials.md` — App Store掲載用の名称・説明文・キーワード・スクリーンショット構成案
- `privacy-policy.md` — プライバシーポリシーの原本
- `privacy-policy.html` — GitHub Pagesで公開するプライバシーポリシー

## 位置づけ
フリーミアム（透かし解除で買い切り）を採用し、サーバー費用ゼロ・アカウント登録不要を基本方針としています。

2. 検証結果を踏まえたMVP実装（技術仕様書 第9〜10章参照）
