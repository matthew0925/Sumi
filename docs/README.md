# ミセルダケ

本人確認書類・個人情報を含む画像を、撮影するだけで自動マスキングするアプリの企画叩き台。

## 中身
- `ミセルダケ_技術仕様書.md` — プロダクト概要、MVPスコープ、iOS/Android実装方針、プライバシー設計、マネタイズ、開発ロードマップ、リスク評価
- `aso-materials.md` — App Store掲載用の名称・説明文・キーワード・スクリーンショット構成案
- `aso-screenshots-draft/` — スクリーンショット下書き用フォルダ（未作成、実装後に追加）

## 位置づけ
「そっと（Sotto）」と並行して検討している、個人開発の買い切り型スマホアプリ企画の叩き台。
フリーミアム（透かし解除で買い切り）を採用し、サーバー費用ゼロ・アカウント登録不要の設計を
基本方針としている。
