# アクセシビリティ監査

基準：WCAG 2.1 AAを参考にしたiOSアクセシビリティ確認

## 確認項目

- Dynamic Type最大設定で主要画面がスクロールでき、操作ボタンへ到達できる
- 主要ボタンにテキストまたはAccessibility Labelがある
- マスク候補は状態を「マスク対象／対象外」と読み上げる
- 色だけに依存せず、件数・状態をテキストでも表示する
- 主要タップ領域は44pt以上を確保する
- システムカラーを利用し、ライト／ダークモードのコントラストを維持する
- エラーはアラートのタイトルと説明文で通知する
- オンボーディング、書類選択、検出、スタイル、書き出し、設定の順序が論理的である

## 実施結果

- ブロッカー：なし
- Dynamic Type：スタイル画面をScrollView化し、小画面・大文字でも次へ進める構造に修正済み
- VoiceOver：主要操作のラベルと状態表現をコードおよびSimulatorのアクセシビリティ階層で確認
- マスク候補：タップ操作、状態ラベル、Button traitあり
- 画像プレビュー：用途を説明するラベルあり
- 設定項目：標準のList／Link／Buttonを使用

## リリース前の実機確認

実機でVoiceOverを有効にし、一本指右スワイプだけで次の経路を完走します。

`オンボーディング → 写真選択 → 書類選択 → 候補切替 → スタイル → 書き出し → 設定`

カメラと写真選択はOS標準UIを含むため、実機で権限ダイアログと読み上げ順を最終確認します。
