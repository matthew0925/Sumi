## 説明文（本文）

```
その身分証の写真、住所まで見えていませんか？

「ミセルダケ」は、本人確認書類を撮影するだけで、隠すべき個人情報を自動で
見つけてマスキングするアプリです。

■ 撮るだけで、隠す場所が分かる
運転免許証、マイナンバーカード、健康保険証などを撮影すると、住所・生年月日・
個人番号・QRコードなど、隠した方がいい場所を自動で検出します。

■ 最終確認はあなたの目で
自動検出はあくまで候補。マスキングする場所は指でタップして追加・解除でき、
範囲も自由に調整できます。「隠したつもりが隠れていなかった」を防ぎます。

■ 端末の中だけで完結
撮影した画像は一切サーバーに送信しません。処理はすべてこの端末の中だけで
行われます。アカウント登録も不要です。

■ フリマ・単発バイト・賃貸契約に
個人間取引の本人確認、単発バイトの応募、賃貸物件の入居審査など、身分証の
写真を送る場面で、不要な個人情報まで晒してしまうのを防ぎます。

■ 無料で試せます
無料版でも全ての機能をお使いいただけます（書き出し画像に控えめな透かしが
入ります）。透かしの解除は、一度のお支払いで完了する買い切り価格です。
サブスクリプションはありません。
```
